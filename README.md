## streechとは？

streechは、ブロックを増やしたScratch modです。

## scratch-guiを利用しています

streechはscratch-guiを利用して開発されています。

## リポジトリの移行について

Streechは、旧リポジトリから新しいリポジトリへ移行しました。

旧リポジトリは現在アーカイブされており、読み取り専用です。

今後の更新は、このリポジトリで行われます。
